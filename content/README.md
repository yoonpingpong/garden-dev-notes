# 개발 학습 노트

## 🦔가 정원 한 켠에 한 줄씩 키워가는 학습 메모

언어, 프레임워크, 아키텍처, 데이터베이스, 인프라, 도구 — 분야별로 정리합니다.

## 구조

```
.
├── language/        프로그래밍 언어 (Python, Java, JS/TS …)
├── framework/       프레임워크/라이브러리 (FastAPI, Pydantic, React …)
├── architecture/    아키텍처/설계 패턴 (Clean, DDD, Design Patterns …)
├── database/        DB 관련 (PostgreSQL, Redis …)
├── infrastructure/  인프라/운영 (Docker, K8s, AWS, Observability …)
├── concepts/        언어/도구 무관 개념 (네트워킹, 보안, 분산 시스템 …)
├── tools/           개발 도구 (Git, uv, ruff, Obsidian …)
└── decisions/       ADR (의사결정 기록)
```
