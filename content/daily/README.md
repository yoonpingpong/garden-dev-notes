# Daily Notes

학습 일기. 그날 배운 것 / 의문점 / 작성한 문서를 짧게 기록.

## 권장 형식

```markdown
# 2026-05-02

## 학습한 내용
- [[language/python/typing/annotated]] 본질 이해
- [[language/python/typing/protocol]] vs ABC 차이

## 의문점
- FastAPI lifespan과 startup event 차이 → 내일 확인

## 작성한 문서
- [[framework/fastapi/dependency-injection]]
```

## Obsidian 데일리 노트 플러그인

- **Settings → Daily notes** 활성화
- **New file location**: `daily/`
- **Date format**: `YYYY-MM-DD`
- **Template** (선택): 위 형식을 템플릿화
