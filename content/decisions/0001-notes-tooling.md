## 컨텍스트

기술 학습 내용이 누적되는 개인 노트 시스템이 필요했다. 요구사항:

- **시간이 흘러도 누적 자산이 되는** 구조
- **검색/연결**이 빠른 시스템
- **백업/동기화** 가능
- **락인 없음** — 도구 바뀌어도 내용은 유지
- **버전 관리** — 학습 진화 추적

## 고려한 대안

### 1. Notion
- **장점**: UI 깔끔, 협업 쉬움, 모바일 좋음
- **단점**: 마크다운 호환성 약함, 락인, 버전 관리 X, 오프라인 제약

### 2. 단순 마크다운 + 디렉토리
- **장점**: 가벼움, 도구 무관
- **단점**: 백링크/그래프 없음, 검색 약함

### 3. Logseq
- **장점**: 아웃라이너 스타일, 마크다운 호환
- **단점**: 블록 단위 설계가 산문체 노트에 어색

### 4. Git + Obsidian ✅
- **장점**: 마크다운 표준, 백링크/그래프 뷰, Git으로 버전/백업, 락인 없음, 풍부한 플러그인
- **단점**: 초기 세팅 필요, Obsidian의 `[[]]` 문법은 표준 아님 (단, 수동 변환 가능)

## 결정

- **Vault 위치**: `~/workspace/garden-dev-notes/`
- **도구 조합**:
  - Obsidian — 작성, 백링크, 그래프 뷰
  - Git — 로컬 버전 관리
  - GitHub (선택) — 원격 백업/동기화
- **문서 형식**: 마크다운 + YAML frontmatter

## 근거

- **Obsidian의 백링크**가 "연결된 개념" 학습에 압도적
- **Git의 히스토리**가 "내 이해의 진화" 자체를 자산화
- 두 도구 모두 **마크다운 위에서 동작** — 어느 한쪽이 망가져도 텍스트는 살아남음
- **로컬 우선** — 인터넷 없어도 작동

## 결과 / 트레이드오프

### 얻은 것
- 6개월 후 학습 내용 즉시 검색 가능
- 백링크 그래프로 학습 사각지대 시각화
- 같은 주제를 여러 각도에서 정리해도 연결됨
- Git 커밋 로그가 곧 학습 이력서

### 포기한 것
- 협업 편의성 (개인 vault 우선)
- 풍부한 미디어 임베드 (Notion 대비)
- 즉각적인 모바일 편집 경험 (Obsidian Sync 유료 또는 git 모바일 앱 필요)

## 후속 영향

- 모든 노트는 **마크다운 + frontmatter** 표준 준수
- 문서 타입 4분류 (`concept` / `pattern` / `reference` / `decision`) 강제
- 새 도구 도입 시 마크다운 호환성을 1순위 기준으로 평가
